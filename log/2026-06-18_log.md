# 2026-06-18 アップデート内容

## 通知用文面

本日のアップデートでは、ダッシュボードの見やすさを整理し、新機能「マイアビリティ」を追加しました。
あわせて、マスターがウエイト種目・野球指標の項目や能力評価設定を管理できる「種目設定」を追加しています。

## 追加

- 新しいページ「マイアビリティ」を追加
- 4属性「瞬発・出力・筋力・柔軟性」を菱形グラフで表示
- 140km/hラインを基準点として破線表示
- 各属性の現状点数、基準点、到達率、反映項目を表で表示
- マスターは選手を選択してマイアビリティを確認可能
- マスター専用メニュー「種目設定」を追加
- 種目設定で、ウエイト種目・野球指標の追加、編集、削除に対応
- 種目ごとに属性、140km/hライン、基準点、単位、評価方向を設定可能
- 種目設定を Firestore の `appSettings/itemDefinitions` に保存
- グラフ直下に直近の数値を小さく表示
- ダッシュボード下部の履歴に、履歴専用の項目選択プルダウンを追加
- マスター向けに、週ごとの入力状況を最近4週＋過去週選択で確認できる表示を追加
- マイアビリティに、ダッシュボードと同じ期間フィルターを追加
- マスター用のマイアビリティ表示フィルターを追加
  - 学年
  - 個別選手
  - ポジション
  - 除外学年
  - 除外ポジション
  - 除外選手
- 種目設定に、採用値の選択を追加
  - Max
  - Ave
- 種目設定に、正規化方式の選択を追加
  - 140km/hライン基準
  - 手動設定
- 種目設定に、手動正規化用の1点ライン・100点ラインを追加
- 種目設定に、入力方式の選択を追加
  - 重量
  - m
  - 回数
  - 4段評価
  - 不採用

## 修正

- ダッシュボードの体重グラフと体脂肪率グラフを分離
- ダッシュボードの期間フィルターを `1week / 1month / 3months / 6months / all` に整理
- ダッシュボード上部カードを体重・体脂肪率の Max / Ave / Growth rate 表示に整理
- Growth rate を割合ではなく、体重は kg、体脂肪率はポイント表記に変更
- 球速推移グラフを削除し、ウエイトトレーニング・野球指標の選択肢と連動する構成へ変更
- マスター用フィルターを折りたたみ式にして画面の圧迫を軽減
- モバイルのグラフタブ初期表示を調整
- ウエイト種目・野球指標の定義を共通化し、ダッシュボード、履歴、ランキング、マイアビリティで同期
- 履歴表示と週別入力状況を、アクティブなグラフではなく履歴専用プルダウンに連動するよう修正
- Firestore ルールに `appSettings` の読み書き権限を追加
- 選手側のマイアビリティは、自分のグラフ・表だけを表示するよう修正
- マスター側のマイアビリティは、複数選手の絞り込み集計に対応
- マイアビリティの点数計算を、種目ごとの Max / Ave 設定に従うよう修正
- マイアビリティの点数計算を、手動正規化設定に対応
- 入力フォームと履歴編集フォームで、種目ごとの入力方式に応じて表示・入力制限が変わるよう修正
- 重量以外の入力方式では、回数・セット欄を表示しないよう修正
- 単位仕事量グラフは、重量入力の種目だけを対象にするよう修正
- キャッシュ対策として `index.html` の CSS / JS 読み込みバージョンを `v14` に更新

## 修正内容まとめ

- マイアビリティの閲覧権限を整理
  - 選手は自分の能力グラフ・表のみ閲覧
  - マスターはダッシュボード同様の条件で対象を絞り込み
- マイアビリティの集計条件を強化
  - 表示期間を選択可能
  - 種目ごとに Max / Ave を選択可能
  - 種目ごとに手動正規化を設定可能
- 種目設定を拡張
  - 入力方式を重量・m・回数・4段評価・不採用から選択
  - 編集時も同じ入力方式を反映
  - 不採用にした種目は入力・グラフ対象から除外
