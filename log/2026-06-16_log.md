- ログイン時の登録済みユーザー選択に、名前検索（前方一致）を追加
- ランキングの対象種目を、実際の記録・選択肢から動的に作成するように変更
- チャットタブの画面を復旧・追加

- スタッフ/その他、院2 などの学年・ポジション選択肢を追加

## 修正

- ログイン画面・登録画面で、同じ ID の入力欄が混在して誤った値を参照する問題を修正

- 選手データ取得時に、Firestore のドキュメント ID が正しく優先されるよう修正
- スマホ版メニューボタンをヘッダー右側へ移動し、開閉しやすく修正
- PC版/スマホ版表示切替ボタンの表示更新を安定化
- 存在しないタブを開こうとした場合にエラーにならないよう修正
- メディシンボール系の記録では、体重比グラフを計算しないよう修正
- CSV 出力で日本語が文字化けしにくいよう BOM 付き CSV に対応
- アプリ表示バージョンを `v2.7` に更新
- キャッシュ対策として `index.html` の CSS / JS 読み込みバージョンを `v11` に更新
